✓ Hiểu quan hệ khóa chính/khóa ngoại   ✓ Viết INNER JOIN và LEFT JOIN

✓ Viết SELF JOIN   ✓ Kết hợp JOIN với WHERE, ORDER BY, LIMIT

Cú pháp cốt lõi

SELECT ...
FROM table1 AS a
INNER JOIN table2 AS b
    ON a.key = b.key
WHERE ...
ORDER BY ...
LIMIT n;
Môi trường thực hành: SQL chạy bằng SQLite ngay trong trình duyệt. Các cú pháp JOIN trong tutorial tương thích với MySQL. Trang cũng mô phỏng USE, SHOW TABLES, DESC và hỗ trợ hàm CONCAT() thường dùng trong MySQL.
