Mục tiêu học tập

✓ Lấy toàn bộ hoặc một số cột   ✓ Dùng AS   ✓ Tạo cột tính toán

✓ Lọc bằng WHERE   ✓ AND/OR/NOT   ✓ LIKE, IN, BETWEEN, NULL

✓ DISTINCT   ✓ ORDER BY   ✓ LIMIT

Cú pháp cốt lõi

SELECT column1, column2, ...
FROM table_name
WHERE condition
ORDER BY column
LIMIT n;
Môi trường thực hành: SQL chạy bằng SQLite ngay trong trình duyệt. Các cú pháp SELECT trong bài tương thích với MySQL. Trang cũng mô phỏng USE classicmodels, SHOW TABLES và DESC table.
