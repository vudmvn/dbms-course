Kiến thức trọng tâm về Index

Index là cấu trúc giúp MySQL truy cập một số tập dữ liệu nhanh hơn. B-tree index thường hữu ích cho phép so sánh, phạm vi, prefix LIKE, JOIN và một số cách sắp xếp. Index đổi lại chi phí lưu trữ và bảo trì khi INSERT/UPDATE/DELETE.

Single-column index

Một cột làm khóa truy cập bổ sung.

CREATE INDEX idx_customer_country ON customer_search(country);

Composite index

Thứ tự cột trong index rất quan trọng; không tương đương các index đơn lẻ.

CREATE INDEX idx_order_customer_date ON order_search(customer_id,order_date);

Metadata và statistics

Dùng SHOW INDEX, SHOW CREATE TABLE và INFORMATION_SCHEMA.STATISTICS để kiểm tra cấu trúc index.

SHOW INDEX FROM order_search;

Optimizer / EXPLAIN

Cần xem possible_keys, key, rows, filtered và Extra. Index tồn tại không có nghĩa optimizer chắc chắn chọn nó.

EXPLAIN SELECT * FROM order_search WHERE customer_id=103;
