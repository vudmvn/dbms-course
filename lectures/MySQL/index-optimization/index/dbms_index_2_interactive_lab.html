Kiến thức trọng tâm — Index 2

Tutorial 2 bám sát tài liệu gốc và chuyển các yêu cầu giải thích thành câu hỏi trắc nghiệm, các yêu cầu viết lệnh thành SQL tự chấm theo cấu trúc.

UNIQUE vs PRIMARY KEY

UNIQUE giữ business-key distinctness; nullable UNIQUE có thể nhận nhiều NULL.

CREATE UNIQUE INDEX uq_customer_email ON customer_search(email);

Prefix & selectivity

Đánh đổi kích thước index với distinct prefix; không dùng UNIQUE prefix cho full email.

CREATE INDEX idx_customer_email_prefix ON customer_search(email(12));

Invisible & Descending

Invisible bị optimizer bỏ qua theo mặc định nhưng vẫn duy trì; descending key part giúp mixed-order.

ALTER TABLE customer_search ALTER INDEX idx_customer_country INVISIBLE;

Composite & clustered

Leftmost-prefix quyết định khả năng truy cập; secondary index records chứa primary key của InnoDB.

CREATE INDEX idx_order_customer_date ON order_search(customer_id,order_date);

Cardinality & functional

Cardinality trong SHOW INDEX là estimate; ưu tiên rewrite date range trước khi thêm expression index.

CREATE INDEX idx_order_year ON order_search ((YEAR(order_date)));

Workload-driven

Chọn index từ query predicates, join, sort, selectivity, chi phí ghi và benchmark.

ANALYZE TABLE order_search;
