Kiến thức trọng tâm — Index 3

Tutorial 3 bám sát tài liệu gốc và chuyển các yêu cầu giải thích thành câu hỏi trắc nghiệm, các yêu cầu viết lệnh thành SQL tự chấm theo cấu trúc.

EXPLAIN trước hint

possible_keys là candidates, key là index chọn; rows, filtered và Extra là phần diễn giải quan trọng.

EXPLAIN SELECT * FROM order_search WHERE customer_id=103;

USE INDEX

Giới hạn tập index ứng viên; không bảo đảm optimizer phải dùng index đã nêu.

FROM order_search USE INDEX(idx_order_customer_date)

FORCE INDEX

Tăng cost tương đối cho table scan; không sửa được index thiết kế sai hoặc predicate không phù hợp.

FROM order_search FORCE INDEX(idx_order_customer_date)

IGNORE INDEX

Loại index khỏi consideration để kiểm tra giả thuyết/độ dư thừa, cần benchmark.

FROM order_search IGNORE INDEX(idx_order_customer_date)

FOR JOIN / ORDER BY / GROUP BY

Scope giới hạn phần của optimizer được tác động; không trộn USE/FORCE cùng table + scope.

USE INDEX FOR ORDER BY(idx_order_status_date)

Hints là phương án sau cùng

Ưu tiên rewrite, composite index, ANALYZE TABLE, benchmark và review tương thích version.

SELECT /*+ INDEX(o idx_order_customer_date) */ ...
